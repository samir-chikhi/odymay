# Odymay

Site vitrine d'Odymay, mobilier vintage rénové par Marie (Montauban). Les pièces sont exposées au tiers-lieu Le Génie, 12 rue du Génie.

**État : maquette V2 du 14/10/2026 (refonte graphique).** Les éléments en orange sur la page sont à compléter avant la mise en ligne publique : coordonnées, horaires, places en atelier, mention TVA, mentions légales.

## Contenu
- `index.html` : page unique (pièces disponibles, atelier « Tapisser un tabouret », présentation, contact).
- `img/` : photos des pièces prises au Génie.

## Mise en ligne
GitHub Pages : Settings > Pages > Deploy from a branch > `main` / root.

## Formulaire
Le formulaire ne transmet rien pour l'instant. Il sera relié au workflow n8n « ODYMAY – Demandes du site » (webhook `/webhook/odymay-contact`).
